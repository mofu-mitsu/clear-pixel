# Clear Pixel

ブラウザ内でシャープ化・ノイズ軽減などを調整できる、シンプルな画像補正ツールです。

## Features

- シャープ化・ノイズ軽減・圧縮ノイズ軽減・なめらか補正
- 補正前／補正後のプレビュー
- PNG / JPEG で保存
- 画像を外部サーバーに送信せず、ブラウザ内で処理
- スマートフォン・PC対応
- 使い方・処理方法を説明するヘルプモーダル

## Files

- `index.html` — ページ構造
- `style.css` — デザイン・レスポンシブレイアウト
- `script.js` — 画像読み込み、補正、プレビュー、保存

## Use

1. `index.html` をブラウザで開くか、GitHub Pagesで公開します。
2. 画像を選択します。
3. スライダーで補正の強さを調整します。
4. PNGまたはJPEGを選んで保存します。

## Publish with GitHub Pages

1. Repository の **Settings → Pages** を開きます。
2. **Deploy from a branch** を選択します。
3. Branch を `main`、folder を `/(root)` に設定して保存します。
4. 公開処理が完了すると、GitHub Pages のURLから利用できます。

## Notes

- 外部API、AIモデル、外部AIサービス、追加ライブラリは使用していません。
- 画像処理はブラウザ内のCanvas APIで行います。画像データをサーバーに送信しません。
- プレビューや保存時の処理負荷を抑えるため、長辺が1600pxを超える画像は縮小されます。保存画像もこの処理サイズになります。
- 本ツールはピンぼけを完全に復元するものではありません。シャープ化は輪郭を強調する処理で、強すぎると縁取りやノイズが目立つ場合があります。
- ノイズ軽減などは周辺画素を使った軽量な処理であり、AIによるディテール再構成は行いません。
