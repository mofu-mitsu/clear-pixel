# Clear Pixel

**AIを使わず、自然にくっきり。**  
ブラウザ内でシャープ化・ノイズ軽減・圧縮ノイズ軽減を調整できる画像補正ツールです。

## Features

- 画像のシャープ化（アンシャープマスク）
- ノイズ軽減
- JPEGなどの圧縮ノイズを目立ちにくくする調整
- 画像全体への軽いなめらか補正
- 補正前／補正後のプレビュー
- PNG / JPEG で保存
- 画像を外部サーバーに送信せず、ブラウザ内で処理
- スマートフォン・PC対応

## Use

1. `index.html` をブラウザで開くか、GitHub Pagesで公開します。
2. 画像を選択します。
3. スライダーで補正の強さを調整します。
4. PNGまたはJPEGを選んで保存します。

## Publish with GitHub Pages

1. Repository の **Settings → Pages** を開きます。
2. **Deploy from a branch** を選択します。
3. Branch を `main`、folder を `/(root)` に設定して保存します。
4. 公開処理が完了すると、GitHub Pages のURLから利用できます。

## Notes

- 外部API、AIモデル、追加ライブラリは使用していません。
- 画像処理はブラウザ内のCanvas APIで行います。
- 本ツールは実際のピンぼけを完全に復元するものではありません。シャープ化は輪郭を強調する処理であり、強すぎると縁取りやノイズが目立つ場合があります。
- ノイズ軽減・圧縮ノイズ軽減は近傍画素を使った軽量な処理です。専用の高度な復元モデルではないため、画像に合わせて強さを調整してください。
- プレビュー処理の負荷を抑えるため、長辺が1800pxを超える画像は処理用に縮小されます。保存画像もそのプレビュー処理サイズになります。
